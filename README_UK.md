# Ласкаво просимо до мого GitHub профілю! 👋

Я розробник, захоплений сучасними веб-технологіями та низькорівневим програмуванням.

## 🌟 Про мене

- 💻 Займаюся Front-end розробкою та C++.
- ⚛️ Вивчаю та створюю проєкти з використанням React, TypeScript і сучасного JavaScript.
- 🎨 Люблю створювати адаптивні та зручні користувацькі інтерфейси.
- 🧠 Також маю досвід роботи з низькорівневими концепціями програмування, керуванням пам’яттю та арифметикою вказівників у C++.
- 🚀 Постійно вивчаю нові технології та вдосконалюю свої навички.
- 🌍 Цікавлюся open source, архітектурою програмного забезпечення та сучасною веб-розробкою.
